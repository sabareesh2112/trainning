# 3D Model Directory

Place your 3D models here in GLB or GLTF format:
- `jwst.glb` -> James Webb Space Telescope 3D Model
- `hubble.glb` -> Hubble Space Telescope 3D Model

The COSMIC LENS 3D Viewer is pre-configured to automatically load these files.
You can also drag and drop or upload any custom .glb or .gltf file directly inside the interactive 3D Viewer in the app!
